# Juhan kommentit sivuston teksteihin (lokakuu 2026)

Kaikki alla olevat muutokset on tehty teemaan (sivupohjien tekstiversio 2). Jo luoduille sivuille
uudet tekstit saa kohdasta **Ulkoasu → Kameli Audio -asennus** (”Uudemmat tekstit saatavilla”).

**Yleislinja:** puhutaan äänen sijaan kokonaisvaltaisemmin tekniikasta. Kalusto kehittyy niin, että
valmiuksia on myös valo- ja muuhun tekniseen toteutukseen, ja puuttuvat palvelut voi alihankkia.

| Sivu | Kommentti | Tehty |
|---|---|---|
| Etusivu | ”Tapahtumatekniikka · Studio · Vantaa” – Vantaa jäi mobiilissa yksin riville | Vantaa pois yläotsakkeesta (Vantaan Hakkila mainitaan heti alla) |
| Etusivu | ”Tapahtumien äänentoistoa ja studiotuotantoa…” | → ”Tapahtumien teknistä toteutusta sekä studiotuotantoa Vantaan Hakkilasta” |
| Etusivu | ”Hoidamme tapahtumasi äänen suunnittelusta purkuun” | → ”…tekniikan suunnittelusta purkuun” |
| Kortit | Yritystapahtumat | → ”Ammattimaiset tekniikkapalvelut konferensseihin, messuille ja yritystilaisuuksiin.” |
| Kortit | Yksityistapahtumat | → ”Tee juhlastasi ikimuistoinen parhaalla mahdollisella ääni- ja valokalustolla.” |
| Kortit | Bändit & Artistit: live mukaan, ”ammattilaisille” pois | → ”Live- ja studiotuotannot saman katon alla – demoista valmiisiin julkaisuihin.” |
| Palvelut | ”täydellinen äänielämys” | → ”täydellinen elämys”; lisäksi ”ääniratkaisuja” → ”ääni- ja valoratkaisuja”, otsikko ”Tekniikkaratkaisut…”, alaotsikko ”ammattitason tapahtumatekniikkaa ja studiopalveluita” |
| Yritykset | ”Huolellisesti suunniteltu ääni luo…” | → ”Huolellisesti suunniteltu ääni ja valo luovat tunnelman, varmistavat sujuvuuden ja tekevät…” |
| Yritykset | ”Musiikki soi laadukkaasti ilman liian kovaa…” | → ”Musiikki soi halutulla alueella tasaisella volyymilla ja laadukkaasti” |
| Yksityiset | Alaotsikko | → ”Näyttävä valaistus ja tehokas äänentoisto tekevät juhlastasi ikimuistoisen.” |
| Yksityiset | Häät uusiksi valaistus mukaan | Teksti uusittu + ”Valaistus luo tunnelman juhlasaliin ja tanssilattialle” |
| Yksityiset | ”…puretaan huomaamattomasti” | → ”…huomaamattomasti teidän aikataulunne mukaan” |
| Yksityiset | ”merkkipäivät ansaitsevat äänen, joka…” | → ”äänen ja valaistuksen, jotka tukevat…” |
| Yksityiset | ”Äänentoisto esiintyjille ja juontajalle” | → ”Äänentoisto ja valaistus esiintyjille ja juontajalle”; ”Ääniteknikko paikalla” → ”Teknikko paikalla” |
| Artistit | ”tuomme tarvittaessa tuoreen näkökulman” | ”tarvittaessa” pois |
| Artistit | ”Selkeä suunnitelma äänityspäiville” | → ”Laaditaan valmis tuotantosuunnitelma aikatauluineen” |
| Artistit | Studion nimi | → ”Äänitys Oasis Studiolla” / ”Äänitämme Oasis Studiollamme Vantaan Hakkilassa.” (myös yhteystiedot ja footer) |
| Artistit | ”Kokonaiset levyt, EP:t ja yksittäiset singlet” | → ”Pitkäsoitot, EP:t sekä singlejulkaisut” |
| Artistit | ”Ääniteknikko, joka on itsekin esiintyjä” | → ”Studiomestari, joka on itsekin esiintyjä” |
| Artistit | Live-tuotanto tärkeä mainita (PA-treenit, kiertuepreppaus, soundien haku) | Uusi rivi ”Live-tuotannot”, alaotsikko ”Live- ja studiotuotannot saman katon alla…” |
| Blogi | ”vinkkejä tapahtumien äänen suunnitteluun” | → ”…tekniikan suunnitteluun” (myös Artikkelit-kategorian kuvaus) |

Linjan mukaisesti myös ”Miksi Kameli Audio” -osion otsikko ”Ääni, josta ei tarvitse huolehtia” →
”Tekniikka, josta ei tarvitse huolehtia”.

Ennallaan (päätettävä): etusivun pääotsikko ”Ääni, joka kantaa.” ja toimintakehote
”Tarvitsetteko äänituotannon seuraavaan tapahtumaan?”.
